# Bank Fraud Transaction Analysis

An exploratory data analysis and visualization project that analyzes
bank transaction data to identify fraud patterns based on transaction
time and other transaction characteristics.

The project uses Python, Pandas, SciPy, Matplotlib, Seaborn, and Tableau
to clean, analyze, visualize, and interpret transaction data.

## Key Analysis

- Data cleaning and preprocessing
- Transaction amount descriptive statistics
- Time-of-day feature engineering
- Fraud vs non-fraud analysis
- Chi-Square Test of Independence
- Bar Chart visualization
- Heatmap visualization
- Interactive Tableau dashboard
- Tableau Public deployment

## Technologies

- Python
- Pandas
- SciPy
- Matplotlib
- Seaborn
- Tableau Public

## Key Finding

The Chi-Square test is used to determine whether time of day and fraud
status have a statistically significant relationship at the 5% significance
level.

## Project Structure

The repository contains the Python implementation, cleaned dataset,
visualization outputs, Tableau dashboard work, and project documentation.
